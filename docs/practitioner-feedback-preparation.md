# Practitioner feedback preparation — no interview conducted

Prepared 12 October 2026 for the submission handoff. No practitioner has
answered these questions; no institution, endorsement, baseline or field
benefit is established. Fredrick can use this guide to collect consented,
dated feedback. Keep personal contact details and private records outside Git.
A sanitized note may identify the institution and role only with permission.

| Topic | Question to resolve | Evidence to retain |
|---|---|---|
| Institutional scope | Which named extension office/cooperative would use this, and who owns the advisory decision? | Confirmed institution/role, date and consented scope note. |
| Representative task | Which crop/variant/grade, origin, three candidate markets and sale quantity are useful? | Practitioner-defined task; distinguish it from the invented two-market fixture. |
| Comparable prices | Are units, grade, wholesale/retail basis and observation dates comparable? What freshness policy is acceptable? | Explicit unit definitions and source-policy rationale; no assumed sack weight or universal seven-day rule. |
| Costs and capacity | Which transport, handling, fees, loss assumptions and buyer-capacity checks are realistic? | Observed/permitted inputs, source/date and unknowns; do not infer missing costs as zero. |
| Review workflow | Who may approve/reject/request changes, and what must be visible before review? | Named authority/process and revision expectations; test credentials are not institutional authority. |
| Output usefulness | Does the gross-versus-net view, provenance and explicit uncertainty support the actual decision? | Specific feedback on strengths, missing information and unsafe interpretations. |
| Latency | Are the measured multi-minute waits acceptable for this task? | Practitioner response to the actual timing boundary, rather than a promised speedup. |
| Manual baseline | Can the same bounded task be observed manually with equivalent inputs? | Actual start/end, steps and errors if genuinely measured; otherwise mark unavailable. |
| Data permission | Who can authorize acquisition and publication of each real source/record? | Dated permission/licence/attribution and redistribution scope. Public visibility alone is insufficient. |

Present the evidence honestly: browser review times 234.38 and 246.07 seconds;
a separate loopback API run reached review in 249.488 seconds. All prices,

Sanitized feedback record fields: date/timezone, consent scope, institution/role
if permitted, task reviewed, questions answered, specific observations, unmet
