## Implementation and behavior

This extends I01.7's deterministic comparison and stdio server. The graph client discovers both `compare_market_options` and `save_advisory_draft`, reads `synthetic://sokosignal/I01.7`, calls the comparison through MCP, and calls the draft tool through that same MCP session. The server independently recalculates from the fixed fixture before saving; it does not accept caller-authored proceeds. Existing Decimal arithmetic and fixed KES/kg contract remain in force.

The SQLite store keeps an immutable draft version, content hash, source comparison hash, unique workflow/action key, simulated decision and audit events. Creation, decisions and revisions use persistent idempotency; conflicting creation-key reuse fails. The deterministic template carries the synthetic label, quote references, net proceeds, assumptions, limitations and `PENDING_REVIEW`. LangGraph checkpoints use the same local SQLite file and a stable workflow ID as `thread_id`. The graph pauses with LangGraph's `interrupt`; it does not invoke Ollama or make reviewer decisions.

The separate `review` CLI requires reviewer identity, decision, workflow ID, draft ID, version, hash and decision idempotency key. This bounded exercise accepts only the clearly simulated identity `simulated:officer-001`; this string check is not authentication. The database transaction checks the exact current pending draft before recording a decision. A revision creates a new immutable version, supersedes the former version and requires a new decision; an earlier approval remains historical evidence but cannot authorize the new hash/version. Approval only changes internal state. No message, order or delivery action exists.

## Limits

This is a deterministic single-host synthetic spike, not a production workflow. The simulated reviewer ID is caller supplied; there is no authentication, role service or protected officer endpoint. The workflow has no model-driven action selection, Ollama call, live retrieval, farmer messaging, order, delivery or real data. It does not demonstrate crash recovery during an in-flight transaction, concurrent writers, general exactly-once behavior, schema migrations, backup/restore or production-grade authorization. The synthetic capacity and prices are not market evidence. No project gate is passed or changed; independent peer review remains pending.
