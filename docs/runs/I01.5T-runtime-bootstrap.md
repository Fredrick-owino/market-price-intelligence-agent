## The single bounded bootstrap

Command (from the repository root):

```text
SOKOSIGNAL_UV_CACHE="$(mktemp -d /tmp/sokosignal-uv-cache.XXXXXX)"
timeout 600s env UV_CACHE_DIR="$SOKOSIGNAL_UV_CACHE" \
  uv sync --locked --python .venv/bin/python --verbose
```

Exit: `0`. uv reported that the existing lock satisfied workspace requirements,
identified the locked distributions, downloaded the outstanding wheels,
prepared 66 packages in approximately 3 minutes, and installed all 66. The
selected direct versions remained the lock's versions, including FastAPI
0.143.0, Pydantic 2.14.0, LangGraph 1.2.14, SQLite checkpoint 3.1.1, MCP
2.3.0 and Uvicorn 0.54.0.

The verbose output contained repeated reflink warnings:
`Operation not supported (os error 95)`, followed by `falling back`. These are
filesystem copy-on-write warnings; uv completed installation using its
fallback path. They are not dependency or import failures.

## Limitations and readiness boundary

The bootstrap proves that the committed lockfiles can be transferred and that
the selected packages import in the local environment. It does not prove
model performance, real MCP transport behavior, source permission,
practitioner validity, release reproducibility on a fresh machine, or any
project gate. The earlier cache-permission and transfer-timeout evidence is
retained in [I01.5](I01.5-runtime-bootstrap.md) and
[I01.5R](I01.5R-runtime-bootstrap.md). The original MCP v2 boundary and all
lock/license risks remain unchanged.
