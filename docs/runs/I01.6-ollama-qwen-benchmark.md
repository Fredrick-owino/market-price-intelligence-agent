## Official source and installer

The official Linux instructions were read at
<https://docs.ollama.com/linux>. The documented installer command used was:

```text
curl -fsSL https://ollama.com/install.sh | sh
```

Actual result:

```text
>>> Installing ollama to /usr/local
sudo: A terminal is required to authenticate
official_installer_exit=1
```

The pipeline and shell wrapper returned exit `1`. The installer reached the
installation step but could not authenticate `sudo` in this non-interactive
session. This is an installation-permission/TTY blocker, not evidence of an
Ollama package or model incompatibility.
