## Limitations and next dependency-ready work

One baseline succeeded in two development attempts; this is not a reliability
rate or broad task evaluation. Only fixed synthetic data and one own server are
covered. Structured summary equality deliberately sacrifices free prose. Search
is baseline-only, not a live-data importer or general market search policy.
Model restart repeats the bounded prepare node; draft writes remain idempotent,
but inference/tool-read progress is not checkpointed after every step. A total
limit applies per prepare invocation, not cumulatively across process restarts.
Normal process restart and committed-decision recovery do not prove arbitrary
crash/concurrency safety, migrations, backup/restore or general exactly-once effects.
The database and checkpoint updates are separate operations, not one transaction.
Local simulated review is not production authentication. No farmer delivery,
frontend, live data, borrowed MCP server, main merge or gate completion is included.

Next dependency-ready work is a separately assigned bounded borrowed-MCP retrieval
experiment with an approved public URL and retrieval safety controls, plus
independent review when a reviewer is available. Practitioner scope, data rights,
real officer authentication and release prerequisites remain unresolved.
