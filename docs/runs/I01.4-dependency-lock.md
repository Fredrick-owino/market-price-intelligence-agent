## Scope

This task created only dependency manifests, lockfiles and this evidence. No
application source, frontend component, Docker service, database schema, test
or model file was created. No project package was installed into `.venv`, no
`node_modules` directory was created, no Ollama binary/model was downloaded,
and no service was started.

The Python project requires `>=3.12,<3.13`. The resolver used the existing
`.venv` Python 3.12.13 (the system `python3` is 3.14.4) and generated a
platform-aware `uv.lock`. The frontend declares Node `>=22.12.0 <23` and npm
`>=9 <11`; the checked host reported Node 22.22.1 and npm 9.2.0.
